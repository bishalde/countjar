Getting started

CountJar gives every number its own URL. Call the URL to change the number, read it back from anywhere, and watch it on a chart. This page takes you from nothing to a working counter in about five minutes.

How it works

Every counter lives in a workspace and has an address like this:

{% call code() %}{{ site_url }}/api/v2//{% endcall %}

Add an action to the end to change it: /up adds one, /down subtracts one, /set?value=42 sets it. Leave the action off to read the current value. Every call returns JSON.

A counter is either public or private:

  • Public counters can be read and counted up by anyone with the URL, which is what you want for page views, like buttons and polls on a website.
  • Private counters need an API token for every request, which suits sign-ups, sales or anything you count from your own server.

Subtracting, setting exact values and resetting always need a token, even on public counters.

Try it without an account

The demo counter {{ demo_ws }}/{{ demo_counter }} is open to everyone. Run this in a terminal, then run it again:

{% call code("bash") %}curl {{ site_url }}/api/v2/{{ demo_ws }}/{{ demo_counter }}/up{% endcall %} {% call code("json") %}{ "workspace": "{{ demo_ws }}", "name": "{{ demo_counter }}", "type": "count", "visibility": "public", "count": 1285, "counted": true, "created_at": "2026-10-14T08:00:00Z", "updated_at": "2026-10-14T09:12:44Z" }{% endcall %}

It's shared with everyone reading this page, so expect the number to move. To keep your own counters you need an account.

1. Create an account

CountJar has no passwords. Sign in with your mobile number and we text you a 6-digit code. Enter it, choose your name and your first workspace's address (for example acme), and you're in. Accounts and tokens explains sign-in in more detail.

2. Make a counter

In the dashboard, open Counters and choose New counter. Give it a name such as visits and pick a type:

TypeWhat it counts
CounterAnything you add to or subtract from: views, downloads, sign-ups.
LikeOne like per visitor, with a heart button widget.
PollYes or no votes, one per visitor, with live percentages.
Rating1 to 5 stars, one rating per visitor, with the average.

You can also set a step size, a minimum and maximum, and unique-visitor counting so each visitor only counts once a day or once ever. Every account can keep 5 counters.

3. Count something

Call the counter's URL with /up. For a public counter that's all you need:

{% call code("bash") %}curl {{ site_url }}/api/v2/acme/visits/up{% endcall %}

For a private counter, create a token under API tokens and send it in the Authorization header:

{% call code("bash") %}curl -H "Authorization: Bearer cj_your_token" \ {{ site_url }}/api/v2/acme/signups/up{% endcall %} {% call note("warn") %}Treat tokens like passwords. Only use them from your server, scripts or CI, never in code that runs in a visitor's browser.{% endcall %}
